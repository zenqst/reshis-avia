# Решись Авиа

Next.js App Router + React + TypeScript. Локальная демонстрация без API.

```powershell
pnpm.cmd install
pnpm.cmd dev
```

Открыть http://127.0.0.1:3000. Проверки: `pnpm.cmd typecheck`, `pnpm.cmd build`.

## Архитектура FSD

- `app/` — только адаптеры маршрутов Next.js и корневой layout.
- `src/app` — глобальные стили приложения.
- `src/pages/dashboard` — композиция экрана и состояние демо.
- `src/widgets` — шапка, параметры рейса, метрики, график.
- `src/features` — выбор направления и меню профиля.
- `src/entities/flight` — типы и справочник направлений.
- `src/shared` — общие UI-примитивы.

Импорты между слайсами идут через их `index.ts`. Зависимости направлены вниз по слоям; слайсы одного слоя друг друга не импортируют. Маршруты вынесены в корневой `app`, чтобы FSD-слой `src/pages` не стал Next Pages Router.

Шрифты и логотип локальные, в `public/`. Кривые графика рассчитываются в коде. Метрики — демонстрационные; авторизация пока заменена локальным состоянием. Глобальная таблица стилей сохраняет существующий внешний вид при миграции.
